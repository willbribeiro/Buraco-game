Buraco - porte SDL2 para Linux
==============================

Conteudo do tarball
  bin/buraco                                   executavel
  share/buraco/assets/font8x16.bin             fonte VGA usada pela interface
  share/applications/buraco.desktop            atalho para o menu
  share/icons/hicolor/scalable/apps/buraco.svg icone (vetor)
  share/icons/hicolor/256x256/apps/buraco.png  icone (256x256)
  share/doc/buraco/README.md, INSTALL.txt      documentacao
  share/doc/buraco/LICENSE, copyright          licenca (GPL-3.0-or-later)
  README.md, INSTALL.txt, LICENSE              copias na raiz

Requisitos
  SDL2 2.0.18 ou mais novo em tempo de execucao
  (libsdl2-2.0-0 no Debian/Ubuntu, sdl2 no Arch, SDL2 no Fedora).

Rodar sem instalar (tarball)
  ./buraco-linux-x86_64/bin/buraco

  O jogo encontra a fonte em ../share/buraco/assets e grava os saves e o
  buraco.cfg dentro da pasta extraida, entao nao e preciso root nem uma
  pasta de dados do usuario.

Instalar o tarball no sistema
  sudo cp -r bin/* /usr/local/bin/
  sudo cp -r share/* /usr/local/share/
  sudo update-desktop-database /usr/local/share/applications   # opcional
  buraco

  Para instalar em /usr, troque /usr/local por /usr.

Pacote Debian (.deb)
  sudo apt install ./buraco_1.0.0_amd64.deb
  buraco
  sudo apt remove buraco

  Instala /usr/bin/buraco, a fonte em /usr/share/buraco/assets, o atalho, os
  icones e a documentacao em /usr/share/doc/buraco. A dependencia
  libsdl2-2.0-0 (>= 2.0.18) esta declarada no proprio pacote.

AppImage
  chmod +x buraco-x86_64.AppImage
  ./buraco-x86_64.AppImage

  Arquivo unico, com o SDL2 e o runtime C++ embutidos: nao precisa instalar
  nada. Se o sistema nao tiver FUSE, use
  ./buraco-x86_64.AppImage --appimage-extract-and-run.

Desinstalar (tarball)
  sudo rm -f  /usr/local/bin/buraco
  sudo rm -rf /usr/local/share/buraco
  sudo rm -f  /usr/local/share/applications/buraco.desktop
  sudo rm -rf /usr/local/share/icons/hicolor/*/apps/buraco.*
  sudo rm -rf /usr/local/share/doc/buraco

Onde ficam os dados
  Instalado em uma pasta somente leitura (/usr/local, /usr) ou rodando um
  AppImage, o jogo grava saves e configuracao em
  ~/.local/share/buraco/buraco/ (ou em $XDG_DATA_HOME/buraco/buraco/).  Ao
  procurar o jogo gravado mais recente, ele olha as duas pastas e escolhe o
  arquivo mais novo.

  buraco --display-info   mostra config, pasta de saves e fonte resolvida.

Controles e opcoes
  buraco --help           lista as opcoes de linha de comando
  README.md               regras, controles e detalhes do porte
